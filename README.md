# 🐕 강아지 집 찾기

> 길을 잃은 강아지가 주인에게 돌아가는 8비트 러닝 게임

**🎮 [지금 바로 플레이하기](https://[your-username].github.io/[your-repo-name]/)**

---

## 스크린샷

```
🏙️ 도시 거리 → 🌳 공원 → 🌲 숲길 → 🌆 골목
각 스테이지마다 보스 등장!
```

## 게임 소개

폭죽 소리에 놀라 줄이 끊어진 강아지가 4개의 스테이지를 달리며 집으로 돌아가는 여정입니다.

- **4개 스테이지** — 도시 거리 / 공원 / 숲길 / 골목
- **4명의 보스** — 치킨 아저씨 / 간식 할머니 / 소시지 트럭 / 참치 고양이
- **스토리 컷씬** — 스테이지마다 스토리가 펼쳐집니다
- **8비트 BGM + 효과음** — Web Audio API 기반

## 조작법

| 키 | 동작 |
|---|---|
| `↑` / `Space` | 점프 (2단 점프 가능) |
| `↓` | 슬라이드 |
| `← →` | 좌우 이동 |
| `ESC` | 일시정지 |
| `D` | 개발자 모드 (무적 + S키 스킵) |
| `🔊` 버튼 | BGM/효과음 음소거 |

> 모바일은 화면 하단 터치 버튼으로 조작 가능합니다.

- ❤️ **HP 3** 시작, 장애물·보스 공격에 피격 시 감소
- 🦴 **500점마다** HP +1 보너스
- 보스전에서 **뼈다귀 15개** 캐치 → 스테이지 클리어

## 기술 스택

- **Vanilla JS** — 프레임워크 없음, 순수 JavaScript
- **HTML5 Canvas** — 게임 렌더링
- **Web Audio API** — BGM 및 효과음 (외부 라이브러리 없음)
- **단일 파일** — `index.html` 하나로 완결
